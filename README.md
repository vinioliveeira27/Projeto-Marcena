# 🪵 Plano de Cortes para Marcenaria

> Aplicação em desenvolvimento

## 💡 Visão Geral

O **Plano de Cortes para Marcenaria** é um aplicativo desenvolvido em Java com o objetivo de otimizar o planejamento de cortes de materiais como chapas, pranchas e painéis.

A ideia nasceu da necessidade real de marceneiros e pequenos negócios que ainda fazem esse planejamento manualmente — no papel ou de cabeça — perdendo material, tempo e dinheiro. O sistema busca resolver isso de forma simples e prática.

## 🎯 Objetivo

Oferecer ao marceneiro uma ferramenta que, a partir das medidas das peças necessárias e do material disponível, calcule automaticamente o melhor aproveitamento possível, reduzindo ao máximo o desperdício.

## 🔍 Problema que resolve

- Desperdício de material por cortes mal planejados
- Tempo perdido em cálculos manuais
- Dificuldade em visualizar o melhor encaixe das peças
- Prejuízo financeiro por compra excessiva de material

## 🚀 Funcionalidades previstas

- [ ] Cadastro de peças com dimensões (largura x altura)
- [ ] Cadastro do material disponível (chapa/prancha)
- [ ] Cálculo automático do plano de cortes otimizado
- [ ] Visualização do aproveitamento do material
- [ ] Relatório de desperdício e economia gerada

## 🛠️ Tecnologias

- Java
- Eclipse IDE
